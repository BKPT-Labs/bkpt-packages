BKPT clock policy, version 5; it needs an independent review before the graph that cites it is merged. It adds the clock stage to the capability policy and changes none of its rules. It replaces versions 1 to 4, which no merged graph cites.
Scope: one STM32C5 part at a time, as its target states, with HAL2 pack 2.1.0 and the captured c5-hal2-minimal foundation. Oscillator accuracy, start-up time, jitter and the electrical conditions of an external source are not covered.
Clock nodes: every element of the manufacturer's clock descriptor becomes one clock node carrying the descriptor's own type, role, limits and choices, and every connection the descriptor states between two elements becomes one clock input. A node records what can be configured, never what is configured.
Peripheral clocks: for every name under which the SDK's RCC header defines a clock enable function that is compiled for this part, one record lists the functions the header defines under that name: enable, disable, state, reset and the Sleep and Stop mode gates, with the bus group the enable function's body names and the enable field the LL bus header gives it. Whether a line is compiled is decided from the header's own conditional lines and the macros the part's device header defines. A record states what the SDK declares, not that a capability supports the peripheral.
Kernel clocks: for every name under which the SDK declares a kernel clock source setter that is compiled for this part, one record lists the setter, the enumerators of the setter's type and, where the header declares them, the getter, the frequency function and the prescaler functions, and names the descriptor selector the configuration pairs it with. The pairing is made only when the enumerators and the selector's inputs are the same set under the label map the configuration states; an enumerator the configuration names as selecting no input is left out of the comparison.
Instance links: a peripheral clock record is linked to a resource of the graph when that resource's reviewed clock enable function is the record's, when the resource is an unpromoted descriptor instance of the same name, when the manufacturer's configuration mapping lists the instance as an element of the record's name, or when the reference manual's description of the record's enable field names the instance. A clock node is linked to a resource whose instance the descriptor names as clocked by it. A link by equal names says that two sources use one name; it is not a statement about behaviour.
Shared clocks: a selector or divider the descriptor names for more than one instance is marked shared with the instances it names. One setting serves all of them, so a capability that sets it for one instance sets it for the others. The stage records the sharing; it does not refuse a combination of capabilities.
Profile: a clock profile is the set of selections the captured clock configuration makes, with the frequency of every node those selections determine. Each selection is cited at the line that makes it, and a selection that cites no such line is refused. The check of that line is textual and has stated bounds. Before it, the stage joins a line that ends in a backslash to the next one, leaves out comments and the contents of string and character literals, and leaves out a block under an #if or #elif whose condition is a zero literal, with or without parentheses or an integer suffix, up to the next #else, #elif or #endif of the same conditional. A line that is joined to another is then left out altogether, so no joined line can be a making line. The stage evaluates no other condition of the preprocessor, expands no macro and reads no trigraph or digraph. What is left of the cited line has to make the selection in one of three forms, where the value is the selection's SDK symbol, or its number where it has no symbol: a statement that fills the line and assigns the value alone, without a cast, to the field the configuration names for the element; on a line that is not a preprocessor directive, a call of that field whose arguments are each one plain name or number, the value being one of them; or a #define of that field as the value alone. A symbol has to say the selection: a selector's symbol is the enumerator the kernel clock pairing gives the selected input or ends in that input, and any other symbol ends in the selected number. The check guards against a citation that says something else than the configuration; it does not prove what the program does. The stage does not check that the configuration names the right field for an element, that the cited line is compiled under the conditions around it, that it is reached and evaluated when the program runs, or that nothing after it changes the selection; these are reviewed with the configuration. Further lines a selection cites are support and are not judged. A frequency is derived by arithmetic over the descriptor: a source has its stated value, a selector the frequency of its selected input, a divider its input divided by its selected factor, and any other element the frequency of its one input. An element with a single choice needs no selection. A derived frequency above a limit the descriptor states is refused. Derived frequencies are nominal values, not measurements. An assignment says how far the captured configuration runs its clock. It is captured when the clock feeds the system clock, or is derived from the system clock, rests on no component's selection and names no instance that has a peripheral clock record. It is gated for any other clock derived from the system clock: the assignment lists the peripheral clock records of the instances the clock names, the reference manual says that each peripheral clock is enabled by its enable bit, and no assignment says whether one is enabled. Gated does not say that a clock is off. It is not stated when nothing captured switches the clock's source on.
Component selections: a kernel clock selection or divider that a reviewed component makes in its own initialization is assigned under the profile and cited at the line that makes it: a template line that calls the setter binding with the source binding, or a captured line that calls the paired setter with the enumerator, in both cases on a line that is not a preprocessor directive, after the same joining and leaving out and within the same bounds as the check of a selection's line. Each captured initialization the configuration names cites its own line. The assignment names the instance and the capabilities that make the selection, and is stated for the case that the instance is assigned to one of them and that capability's initialization of it has completed successfully. So is every clock derived through it. The stage states such a clock for no other case: a selector's reset selection, which the graph does not record, may be the same input. A selection no such line is found for is refused. A selection the configuration states for a component names its capability and its instance, the capability has to have a role the instance can fill, and its field has to be a function the SDK header declares for the part.
Rate basis: a capability whose rate choices rest on a clock cites the profile assignment of that clock. Where the configuration says so, every choice must divide the assigned frequency exactly, and a configuration with a choice that does not is refused.
Timer clock: the descriptor feeds the timer clock elements from HCLK, the reference manual's clock chapter states that the timer clock frequencies equal HCLK, and the SDK returns the HCLK frequency as the timer kernel frequency. The basic timer chapter of the same manual names the APB clock as the counter clock. Under a profile whose APB prescalers are 1 both readings give one value, and the stage refuses a profile that selects another value than the stated one for a prescaler the configuration names for this rule. The timer clock elements the configuration lists have to be all the elements of the descriptor whose role carries the timer suffix, and the prescalers named have to be exactly the dividers whose descriptor role is the role of such an element without the suffix.
Chapter pointers: the manufacturer's configuration mapping names a reference manual chapter for a configurable element. The pointer is recorded on the peripheral clock record of the same name unless the configuration withholds it and says why.
Nominal sources: an oscillator whose frequency no captured line states is assigned only when the configuration names its nominal value and the lines that state it, and the assignment says that the value is nominal; an assignment derived from it names it. A source the descriptor gives one fixed value is assigned that value without such an entry.
